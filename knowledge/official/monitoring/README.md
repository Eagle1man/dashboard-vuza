# Мониторинг эффективности вузов

Источник: `monitoring.miccedu.ru` — информационно-аналитические материалы
по результатам мониторинга эффективности деятельности образовательных
организаций высшего образования. Использованы выпуски 2024 и 2025 годов.

## Что важно знать перед ответом

- **Год выпуска и год данных не совпадают.** В выпуске 2025 года последний
  измеренный год — 2024. Поэтому «2024» и «2025» в файлах — это годы
  выпусков мониторинга, а не календарь отчётности.
- **E-показатели** (E.1…E.8) — сводные: образовательная деятельность,
  наука, международная деятельность, финансы, зарплата ППС, дополнительный
  показатель. Именно они сравниваются с медианами по РФ, региону и
  ведомственной принадлежности.
- **Медиана региона** — не «средний вуз», а середина списка: половина вузов
  области выше, половина ниже.
- **E.3 (иностранные студенты)** заполнен не у всех вузов области, поэтому
  знаменатель места меньше, чем общее число участников.
- Числа в файлах — как в первоисточнике; округление до двух знаков.
- Показатели E.1…E.8 не заменяют официальную отчётность вуза: это
  сопоставительный срез, а не приёмка.

## Машинная копия

`data/monitoring/structured/` — та же карточка в машинном виде: один факт
на строку в `observations.jsonl`, те же данные в `monitoring.sqlite`,
`indicators.json`, `organizations.json`, `cards/*.json` и `manifest.json`
с контрольными суммами. Собирается без сети:

```
python -m backend.monitoring_store build
python -m backend.monitoring_store lookup --level VO --release 2025 --code 1.3
```

Вопросы чата сначала идут в старую витрину `analytics.db`, а если её
данных не хватает — в структурированную копию (`analytics.try_answer`).
Так разделы I, IV, V и СПО отвечают точным числом, а не пересказом.

## Обновление

Карточку можно перечитать с сайта одной командой:

```
python -m backend.sync_monitoring          проверить и обновить при изменениях
python -m backend.sync_monitoring --full   пересобрать все 38 карточек региона
python -m backend.sync_spo                 то же для карточки СПО
python -m backend.sync_spo --full          пересобрать все 142 карточки СПО
```

Сторож сравнивает отпечаток данных с прошлым запуском и не трогает
файлы, если на сайте ничего не изменилось. При новом выпуске сам
переходит на следующий год. Подробности — в README проекта.
