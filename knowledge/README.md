# Папка `knowledge`

Здесь лежат документы, по которым отвечает ассистент. Индексатор
обходит её рекурсивно и разбирает `.pdf`, `.docx`, `.xlsx`, `.csv`,
`.md`, `.txt`, `.html`.

```
knowledge/
  official/       приказы, отчёты, положения
  org_control/    материалы подразделений по годам
  demo/           демонстрационные файлы с вымышленными числами
  <любая папка>/  индексатор обходит всё
```

## Как индексировать

После добавления или удаления файлов:

```
python -m backend.ingest --prune
```

`--prune` заодно убирает из индекса файлы, которые вы удалили: без него
удалённый документ продолжает находиться в поиске и попадать в ответы.

## Демонстрационные документы

Папка `demo/` содержит восемь файлов с **вымышленными** числами — они
нужны, чтобы интерфейс не был пустым при первом запуске. В интерфейсе
они помечены как демонстрационные.

Перед боевым запуском их лучше убрать: ассистент ищет по всему корпусу,
и вымышленное число из демо-файла легко прочитать как настоящее.

```
удалить knowledge/demo
python -m backend.ingest --prune
```
