# Папка `knowledge`

Здесь лежат документы, по которым отвечает ассистент. Индексатор
обходит её рекурсивно и разбирает `.pdf`, `.docx`, `.xlsx`, `.csv`,
`.md`, `.txt`, `.html`.

## Что в репозитории, а что нет

В git хранится только папка `demo/` — восемь демонстрационных файлов с
**вымышленными** числами. Они нужны, чтобы интерфейс не был пустым при
первом запуске; в интерфейсе они помечены как демонстрационные.

Настоящие документы вуза (отчёты, приказы, опросы работодателей) в
репозиторий **не попадают**: это внутренние данные. Они лежат в этой
папке на рабочей машине и в git не добавляются — правило записано в
`.gitignore`.

## Куда класть свои документы

```
knowledge/
  official/       приказы, отчёты, положения
  org_control/    материалы подразделений по годам
  <любая папка>/  индексатор обходит всё
```

После добавления файлов:

```
python -m backend.ingest --prune
```

`--prune` заодно убирает из индекса файлы, которые вы удалили.

## Перед боевым запуском

Удалите `knowledge/demo` и выполните `python -m backend.ingest --prune`.
Демонстрационные числа не должны смешиваться с отчётными: ассистент
ищет по всему корпусу, и вымышленное число из демо-файла легко прочитать
как настоящее.
