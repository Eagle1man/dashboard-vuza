# Папка `knowledge`

Здесь лежат документы, по которым отвечает ассистент. Индексатор
обходит её рекурсивно и разбирает `.pdf`, `.docx`, `.xlsx`, `.csv`,
`.md`, `.txt`, `.html`.

```
knowledge/
  official/       приказы, отчёты, положения, мониторинг
  org_control/    материалы подразделений по годам
  <любая папка>/  индексатор обходит всё
```

## Как индексировать

После добавления или удаления файлов:

```
python -m backend.ingest --prune
```

`--prune` заодно убирает из индекса файлы, которые вы удалили: без него
удалённый документ продолжает находиться в поиске и попадать в ответы.

## Демонстрационных документов больше нет

Раньше в `demo/` лежали восемь файлов с вымышленными числами — чтобы
интерфейс не был пустым при первом запуске. Они удалены: ассистент ищет
по всему корпусу, и вымышленное число из демо-файла легко прочитать как
настоящее. Каждое число теперь подписано документом.
